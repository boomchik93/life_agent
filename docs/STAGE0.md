# Этап 0: что сделать руками

Токен доступа уже сгенерирован и лежит в `.env` (`ACCESS_TOKEN`). Остальное заполняешь ты.

## 1. Google Calendar: сервисный аккаунт

1. https://console.cloud.google.com → создать проект (например `life-agent`).
2. «APIs & Services» → «Library» → включить **Google Calendar API**.
3. «IAM & Admin» → «Service Accounts» → «Create». Роли не нужны.
4. У аккаунта: «Keys» → «Add key» → «JSON». Файл сохранить как `secrets/sa-key.json` в этом репозитории (каталог в `.gitignore`).
5. Скопировать e-mail сервисного аккаунта (`...@...iam.gserviceaccount.com`).
6. В Google Calendar (веб) для каждого календаря: «Настройки и общий доступ» → «Совместный доступ» → добавить e-mail сервисного аккаунта:
   - календарь, куда агент пишет → «Вносить изменения в мероприятия»;
   - календари только для чтения → «Просмотр всех сведений о мероприятии».
7. **Создай отдельный тестовый календарь** для разработки и расшарь на сервисный аккаунт с правом записи. Все тесты записи идут только в него.
8. В «Настройки календаря» → «Интеграция календаря» взять **Идентификатор календаря**. Записать в `.env`:
   - `CALENDAR_IDS` — id через запятую (для разработки только тестовый);
   - `CALENDAR_WRITE_ID` — id календаря для записи.
9. Если есть ICS-ссылка с расписанием пар — `ICS_URL` (можно позже, этап 2).

## 3. Локальные инструменты (нужно твоё согласие на установку)

Состояние на этой машине:

| Что | Статус |
|-----|--------|
| Go 1.27 | есть |
| adb | есть, устройств не подключено |
| Java 17 | есть |
| Flutter | **нет** |
| Android SDK (cmdline-tools, platform, build-tools) | **нет** |
| Xcode | **нет** (стоят только Command Line Tools) |

Предлагаемая установка через Homebrew:

```bash
brew install --cask flutter
brew install --cask android-commandlinetools
flutter doctor
```

Дальше принять лицензии и поставить платформу: `flutter doctor --android-licenses`, `sdkmanager "platforms;android-35" "build-tools;35.0.0"` (версии сверить с `flutter doctor`).

Xcode нужен только для macOS-сборки (этап 9), сейчас не требуется.

Телефон (S21+): «Параметры разработчика» → «Отладка по USB» (или беспроводная отладка), подключить, проверить `adb devices`.
